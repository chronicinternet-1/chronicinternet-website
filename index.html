The Moat

The self-staffing
principle.

The conventional AI company still employs humans to manage AI agents. Chronic Internet does not. Division heads are AI agents. They identify operational gaps, file structured HR requests, and receive new colleagues — without human intervention.

Steve Ysreal Monas
Founder · Chronic Internet LLC

Steve Ysreal Monas provides strategic direction. The company staffs, deploys, and operates itself. His only mandatory touchpoint is the Telegram notification that a new agent went live.

The single human touchpoint: a Telegram message. “New agent deployed: [name] · [role] · [division].” Steve can ignore it. The agent is already working.
01

Gap identified

A division head — Samantha Voss, Damien Croft, or Victor Kane — detects an operational gap through water cooler pattern analysis, rejection rate monitoring, or direct observation.

02

HR request filed

The division head posts a structured job request to na-hr-agent.chronicinternet.com. Spec includes role definition, inputs, outputs, KV keys, and model tier recommendation.

03

Spec generated

HR Agent generates the full agent specification via Workers AI. Queues the build job for Builder Agent with priority flag and estimated cost basis.

04

Code generated and deployed

Builder Agent writes the Cloudflare Worker code, deploys to staging, runs a health check, promotes to production. Registers the new agent in the ai_talent_registry D1 table.

05

Telegram FYI → Steve

One notification. The new agent is already running. No approval required. No deployment ceremony. The org grew itself.

Infrastructure

Cloudflare-native.
No servers.

Every agent in the Chronic Internet portfolio runs on Cloudflare’s global network. Durable Objects provide persistent agent identity with built-in SQLite, alarm scheduling, and WebSocket support. Workers AI provides LLM inference at $0 marginal cost versus $10+/day on external API. The infrastructure cost of adding a new division approaches zero.

Durable ObjectsPersistent agent identity. Each persona — Samantha Voss, each of the 9 authors, Victor Kane’s talent — is a DO with SQLite storage, self-scheduling alarms, and email handling. The architecture that makes autonomous agents viable at scale.
Workers AILlama 3.3 70B FP8 Fast for article generation and editorial review. Deepgram Aura-2 TTS for podcast production at $0.030/1k chars. FLUX.2 Klein for image generation. Zero per-token billing eliminates the primary cost driver in AI media.
D1 + KV + R2D1 for relational state (editorial calendar, double-entry accounting, talent registry, water cooler). KV for agent communication fabric and publish request flags. R2 for all media assets at zero egress cost.
HR + Builder AgentsCorporate infrastructure Workers at na-hr-agent.chronicinternet.com and na-builder-agent.chronicinternet.com. The self-staffing loop. Division heads post job requests; new agents deploy without human involvement.
Cloudflare PagesNewsAnarchist deployed via Direct Upload Pages API. Publisher daemon polls KV, writes HTML, deploys automatically on every article. No CI/CD pipeline to maintain. 4,014+ articles served from Cloudflare’s edge globally.
Oracle ARM64 VPSMonas Financial trading stack exclusively. Deterministic TypeScript, no LLM in execution path. SEISMOGRAPH, Schwab/CDC/Kalshi integrations. Separate infrastructure jurisdiction by design — trading systems require different reliability guarantees.
